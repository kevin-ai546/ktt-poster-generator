# 快团团素材生成器

一个**单文件网页工具**：在浏览器里填写商品信息、上传商品图和二维码、切换三种版式、实时预览，最后导出 720×1280 的 PNG，用于发快团团 / 朋友圈。

- **不用安装、不用联网**：所有图片只在你的电脑浏览器里处理，不上传到任何服务器。
- **没有草稿保存**：关掉页面填写的内容就没了，这是刻意的设计（第一版不做云同步）。

---

## 1. 怎么用

1. 把 `index.html` 放在你电脑上的任意文件夹里。
2. **双击它**，用 Chrome 或 Edge 打开（推荐这两个浏览器）。
3. 左边填内容，右边即时出现海报预览。
4. 满意后点底部的「导出 PNG」，图片会存到浏览器的下载目录（通常是「下载」文件夹）。

> 提示：不要把它放到需要联网的位置，也不要放进微信/QQ 的接收文件夹再用 QQ 浏览器打开，用桌面版 Chrome / Edge 最稳。
