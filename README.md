# 快团团素材生成器

一个**单文件网页工具**：填写商品信息 → 上传商品图和二维码 → 切换三种版式 → 实时预览 → 导出 **720×1280** 的 PNG，用于发快团团或朋友圈。

**公开网址**：https://kevin-ai546.github.io/ktt-poster-generator/

> 本工具的上线版本由 `index.html` 一个文件构成，样式和脚本都写在里面，**不需要安装、不需要构建、不需要联网**。

---

## 1. 本机打开方式

最推荐的方式（也是开发时验证过的方式）：

1. 把 `index.html` 保存在电脑上任意位置。
2. **双击它**，或用 Chrome / Edge 打开。
3. 左边填内容，右边即时出预览。

注意事项：

- **推荐 Chrome 或 Edge**。其他浏览器（尤其 QQ 浏览器、手机自带浏览器）在导出下载这一步行为可能不同。
- 地址栏会显示 `file://…`，这是正常的——页面本身就是为本地打开设计的。
- 不需要起服务器、不需要 Node / Python，也不联网。

---

## 2. 网页功能

界面分成左右两栏（窄屏时自动变成上下）：

**左 · 编辑区（从上到下 5 块）**

| 分区 | 控件 |
| --- | --- |
| 版式模板 | 居中促销 / 左图清单 / 大图爆款 三个按钮 |
| 基础信息 | 顶部标签、团长昵称／品牌、商品标题、副标题 |
| 图片素材 | 商品主图上传、图片展示比例（4 档）、适配方式（2 种）、二维码上传 |
| 核心卖点 | 默认 3 行，可增删，最多 6 条 |
| 价格和转化文案 | 原价、团购价、团长说、规格／发货信息、按钮主文案、按钮副文案 |

**右 · 预览区**：一块 720×1280 的画布，输入什么立刻显示什么，不需要点"生成"。

**底部**：「恢复示例」和「导出 PNG」两个按钮。

**编辑规则**：所有输入都是即时生效的；未填写的地方显示浅灰占位提示（不会显示 `undefined`）；文字过长时在自己框内换行或加「…」，不会盖住别的区域。

---

## 3. 三种模板

三个模板的差别**不只是颜色**，图文位置也不同（这与参考页一致）：

| | 居中促销 | 左图清单 | 大图爆款 |
| --- | --- | --- | --- |
| 主色 | 红 `#ff4d57` | 青 `#13a8c7` | 橙 `#ff6c35` |
| 主图宽度 | 中等 | **最窄** | **最宽** |
| 主图位置 | 水平居中 | **靠左** | 水平居中 |
| 卖点位置 | 图片下方 | **图片右侧**（每条 2 行） | 图片下方 |
| 顶栏 | 实色底 + 白字 | 白底 + 底部色条 + 深色字 | 实色底 + 白字 |

**怎么选**：单品主推用「大图爆款」；有多条卖点要说明用「左图清单」（卖点排在图片右侧，一眼看完）；常规促销用「居中促销」。

切换模板时，**已填写的文字、价格、卖点、两张图片全部保留**，只是重新排版。

## 4. 导出 720×1280

- 点底部「导出 PNG」，图片会下载到浏览器的下载目录（通常是「下载」文件夹）。
- **尺寸固定为 720 × 1280 像素**，不受你选的图片比例影响——图片比例只改变主图区域，不改变整张海报。
- 文件名形如 `快团团素材-20261026-153012.png`（时间戳到秒，不会覆盖上一次）。
- 导出用的绘图函数与右侧预览**完全相同**，所以预览看到什么，导出就是什么。
- 导出前建议：删掉没写内容的卖点行（留空的行会以浅灰占位出现在图片上）。

---

## 5. 图片在浏览器里处理（不上传）

这是本工具最重要的一条：

- 选图后，图片用浏览器的 `FileReader` 读成本地 DataURL，**只存在于浏览器内存里**，页面关闭即消失。
- **不会上传到任何服务器**，也不会写入 `index.html` 源码或任何本地文件。
- 断网可用；用浏览器 F12 打开 Network 面板走一遍全流程，看不到任何外部请求。
- 支持 PNG / JPG / WEBP，单个文件上限 20MB；格式不对、文件损坏、超过 20MB 都会在页面上给出中文提示，并且**保留上一次成功的那张图**。
- 商品主图和二维码是**两个独立入口**，换主图不会影响已选的二维码。

> 注意：请不要在公共电脑上保留含客户信息的二维码，虽然它不会被上传，但刷新前会留在页面里。

---

## 6. 草稿不会自动保存

第一版刻意**不做草稿保存**：

- 页面没有 `localStorage` / `sessionStorage`，没有云同步，没有后端。
- **刷新或关闭标签页，填写的内容和选中的图片就全部丢失**，回到初始占位状态。
- 所以建议：**先导出 PNG 再关页面**；需要长期保留的内容，请自己记在别处。
- 「恢复示例」按钮会把内容替换成一套示例（会先弹确认框），但它也是"替换"而不是"保存/撤销"，操作不可找回。

## 7. 用 GitHub 网页发布的方法

如果你想自己部署一份（或更新线上版本），步骤如下，**全程在 GitHub 网页完成**：

1. 打开你的仓库（例如 https://github.com/kevin-ai546/ktt-poster-generator ）。
2. 点 **Add file → Upload files**。
3. 把 `index.html` 拖进去。**只需这一个文件**（可选地附带 `README.md`、`AGENTS.md`、`.gitignore`）。
4. **千万不要上传 `work/` 目录**——里面是本地测试素材，GitHub 网页上传不会自动遵守 `.gitignore`，要手动避开。
5. 下方填写提交信息 → **Commit changes** 到 **main 分支根目录**。
6. 进 **Settings → Pages**：Source 选 **Deploy from a branch**，Branch 选 **main / root**，保存。
7. 几十秒到几分钟后，访问 `https://<用户名>.github.io/<仓库名>/` 即可（本项目是 https://kevin-ai546.github.io/ktt-poster-generator/ ）。

更新时重复第 2–5 步覆盖同名文件即可。想回退的话，GitHub 网页支持删除文件或用历史版本回退。

## 10. 遇到问题怎么办

| 现象 | 可能原因 / 处理 |
| --- | --- |
| 双击后是空白画布 | 换 Chrome 或 Edge 打开 |
| 选图后没反应 | 看图旁边的红字提示（格式不支持 / 超过 20MB / 文件损坏） |
| 导出后什么都没发生 | 看底部是否出现红字提示；部分浏览器对本地页下载有限制，换 Chrome / Edge |
| 刷新后内容没了 | 属于设计如此（不做草稿保存），重要内容请先导出 |
| 卖点加不了 | 上限 6 条，删掉一条才能继续加 |
| 二维码扫不出来 | 确认上传的是清晰方图，且导出后没有被压缩转发（微信聊天里的图片会被压缩，尽量用原图） |
